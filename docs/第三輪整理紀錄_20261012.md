## 分類與重複的解讀

指定 run 的 completed 狀態用於定位完成版本；不能據此宣稱全部 baseline 或研究假設已驗證。部分 seeds 的分表／閱讀表優先保留快照身份，不繼承十 seeds 全集身份。smoke、失敗、partial 檔、已退出研究分支、oracle、歷史協定與輔助分析各自標記；沒有足夠規則的五份檔案仍列待確認（兩份舊 FS log、三份 .gitkeep）。

295 個相同內容群分成：233 個跨 seed 同路徑輸出、10 個 analysis 快照複本、52 個跨路徑待核對複本。只證明非空檔案的 bytes 相同，不推論方法無效、樣本獨立或檔案可以刪除。相同大小但不同內容的檔案不列同一群；空檔案不作重複證據。

清冊是生成時點的目錄 metadata 快照，原 results/README 是唯一人工導航項目；其後加入清冊連結不代表研究數據變更。所有逐檔紀錄以原路徑保留，工具自己產生的 results/catalog 不納入盤點，避免每次重建清冊遞迴擴大。

搬移後 Markdown 只改連結，數字與正文保留。舊報告查核 JSON 的 report_sha256 仍指原文版本；搬移清冊提供該原始 hash 與新連結版本 hash，不手改舊查核來表示新查核。
