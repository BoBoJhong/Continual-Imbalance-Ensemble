# 實驗索引

盤點日期：2026-10-12。此索引串接研究目的、程式入口、結果版本與限制；研究決策以[研究方向](研究方向.md)為準。

## 狀態如何閱讀

| 標記 | 意義 |
|---|---|
| 現行／已完成 | 目前可定位的完成 run；不等於所有研究假設、baseline 或論文驗收均完成 |
| 現行／探索 | 保留的擴充實驗，必須交代自身 target、切割與選擇協定 |
| 歷史 | 舊協定或固定時點快照；可追溯，不能直接併入最新比較 |
| 測試／失敗 | 小規模試跑或未完成 run；不用作正式成效表 |
| 待對齊 | 尚缺同條件比較或完整來源紀錄 |
| 已停止／歷史 | 已退出目前研究與待辦，保留既有成果供追溯 |

協定摘要：Old-fit 1999–2011、New-fit 2012–2013；2014 以固定 seed 42 分成互斥 DSEL／Calibration；Test 2015–2018。補值、縮放與 FS 只擬合 Old-fit；FS 後才採樣。under／over／hybrid 分別為 TomekLinks／ADASYN／SMOTEENN。六個 XGBoost 模型為 Old／New × 三種採樣；49 個混合子集依 2／3／4／5／6 模型分成 9／18／15／6／1 組。

動態方法為 DESlib 的 KNORA-E／KNORA-U／OLA／LCA。靜態候選與門檻只用 Calibration 選擇，Test 用於評估。target 是原始公司最終 alive／failed 狀態；不是已驗證的一年後破產事件。使用者已確認目前 New 訓練策略及不要求五折；本索引不新增傳統權重延續 Fine-tune 的必要要求。

## 常用操作

由專案根目錄執行。先查看清單或完成狀態：

```powershell
python scripts/run/run_all_experiments.py --list
python scripts/analysis/study3b_pipeline_status.py results/phase_flexible/study3b_full_pipeline/runs/20260928T185026381432Z
```

以下會新建結果 run，屬於重跑實驗；此次整理未執行：

```powershell
# 核心 Study I：no-FS
python experiments/phase2_ensemble/dynamic/des/bankruptcy_standard_dynamic.py
# 核心 Study II：含 no-FS 對照
python experiments/phase3_feature/bankruptcy_standard_dynamic_fs.py
# 擴充 Study 3B：完整六分類器流程
python experiments/phase_flexible/study3b_full_pipeline.py
```

固定年份與完整 Study 3B 入口均支援 --resume RUN 路徑。重現時依該 run 的 manifest 核對 seeds、參數、source hashes 和套件版本；requirements.txt 與兩個舊 run 的環境不完全一致，不能僅靠固定 seed 保證輸出一致。
