# KHP 健康資料集採用說明

查核日期：2026-11-03。深化檢核後判斷：特徵種類符合研究方向，但已確認問法、疾病碼、附加題涵蓋及樣本變更；僅保留為候選，須完成共同特徵與資訊時間驗收後才能進入正式實驗。[欄位變更及實驗影響檢核](KHP欄位變更與實驗影響檢核_20261103.md)。

擬採用韓國 Korea Health Panel（KHP）第一期縱貫健康調查作為論文的健康領域資料集，以同一位受訪者前一年的健康狀況與醫療利用，預測下一年是否住院，並沿用破產資料的舊期／新期模型、集成與特徵選擇比較框架。

## 資料概要

| 項目 | 內容 |
|---|---|
| 來源 | 韓國保健社會研究院（KIHASA）與國民健康保險公團（NHIS）共同執行的 Korea Health Panel；官方釋出研究資料，實際取得條件仍須確認 |
| 性質 | 同一批家庭及個人的長期健康追蹤調查，包含健康狀況、慢性病、醫療利用、支出、保險與社經資訊；屬調查資料，非完整醫院電子病歷 |
| 年份 | 候選範圍 2008–2018，共 11 個年度，最多可建立 2008→2009 至 2017→2018 共 10 組年度預測；正式起始年須依共同欄位及資訊時間確認 [S1] |
| 規模 | 既有原始研究列出的年度全樣本為 2008 年 21,283 人、2018 年 17,008 人；包含中途增補與失訪，不能視為相同人數全期完整追蹤 [S2] |
| 任務 | 根據第 t 年可取得的資訊，預測同一位受訪者第 t+1 年是否有至少一次住院；需先依事件日期或官方年度整合定義核對特徵期與結果期 |
| 特徵 | 年齡、性別、自評健康、慢性病種類或數量、前一年住院／急診／門診利用、醫療支出、收入、教育與保險等候選特徵；最終保留可跨年對齊且預測時已知的項目 |
| 正例比例 | 本研究比例待實際計算。既有成人研究表 1 的 2011 年住院比例為 9.3%，僅支持住院為少數類別的初步可行性，不代表本研究逐年標籤比例 [S3] |

年份依據：[KIHASA 官方第一、二期設計說明](https://www.kihasa.re.kr/en/publish/hsw/view?seq=40071&volume=40067)。規模依據：[2008–2018 原始研究年度樣本表](https://www.frontiersin.org/journals/public-health/articles/10.3389/fpubh.2022.1048044/full)。住院比例依據：[Sohn 等人（2021），表 1](https://journals.sagepub.com/doi/10.1177/00469580211028171)。

## 為何要用

1. **有明確的未來預測目標。** 可將同一人的前一年資訊與後一年住院結果配對，建立未來事件預測，不只辨識當下是否有疾病。
2. **可長期追蹤同一個人。** 第一期跨越 11 個年度，較符合本次希望同人跨多年觀察的需求；中途增補與退出仍須分別標記。
3. **特徵內容符合研究需求。** 健康狀況、慢性病、醫療利用及社經資訊可構成多變量分類輸入，適合檢驗原有集成與特徵選擇方法。既有研究已使用年齡、收入、慢性病、自評健康等變數分析 KHP 醫療利用 [S4]。
4. **有不平衡分類的可行性。** 文獻成人樣本中住院者為少數；正式實驗仍須確認各年正例數與驗證樣本是否充足，不能直接套用文獻比例。
5. **可保留跨領域比較。** 健康與財務資料可採一致的模型比較規則，評估方法在不同任務的表現；不預設新期或集成一定較好。

## 目前進度

已核對官方調查內容報告與原始研究，確認 KHP 含住院、急診、門診、醫療支出、慢性病、自評健康與社經資訊，**特徵種類符合本研究方向，但尚不能認定 2008–2018 的測量定義穩定**。深化查核確認疾病碼多次改版、慢性病認定調整及部分附加題缺年；直接合併可能使模型辨識問卷／編碼版本，影響舊期／新期與 FS 解讀。住院題數改變本身不證明二元住院標籤失效。詳見[欄位變更及實驗影響檢核](KHP欄位變更與實驗影響檢核_20261103.md)。目前尚未取得並逐年驗收第一期原始資料與代碼簿，也尚未執行預測實驗。

下一步先確認共同欄位與資訊時間，再計算相鄰年度可連結人數、住院正例數、缺失比例與固定受訪者留存情況，最後固定訓練、驗證及測試年份。

限制：官方報告指出，慢性病問法及定義在 2014 年調查前後有調整，疾病分類亦曾改版且轉換未必可靠；各類資訊可能分別以訪問當下、上一年度或上次訪問以來為準。因此，同一個欄位名稱不保證跨年定義一致，年度檔名稱也不保證全部資訊在預測起點已知。調查年與年度資料參照年不能混用；精確改版邊界須以選定版本碼本確認。須先完成對齊，再決定是否可使用全部候選年份。[KIHASA 官方調查檢討報告](https://repository.kihasa.re.kr/handle/201002/32632)，印刷頁 57–70。

此外，KHP 並非所有人全期完整追蹤；每年原始人數不等於有效預測人數，不能先承諾每年 10,000 筆。任務初步定位為任何住院，不直接代表首次住院或非計畫住院；若未使用調查權重，結果僅代表研究樣本。

## 附錄：候選特徵與驗收要求

以下列出特徵概念，非已驗收的原始欄名清單。尚未完成各年字典對照，不杜撰欄位代碼或承諾每項全年度皆可用。

| 類別 | 候選特徵 | 本研究用途及必要檢查 |
|---|---|---|
| 人口背景 | 年齡、性別、婚姻、教育 | 一般風險與背景輸入；年齡需對應預測起點，類別跨年對照 |
| 健康狀況 | 自評健康、可比較的活動限制 | 反映個人健康狀態；需核對成人附加問卷的年份、作答時間與缺失 |
| 慢性病 | 可對齊的慢性病種類、疾病數 | 反映既有疾病負擔；2014 前後定義與編碼不可直接接合。診斷只可用預測前已知資訊 |
| 醫療利用 | 住院有無／次數、急診次數、門診次數；住院天數視共同欄位決定 | 反映既往利用；從事件檔彙整為一人一年，不能把每次就醫當獨立受訪者 |
| 醫療支出 | 前一年個人醫療支出、自付費用 | 反映既往利用與費用負擔；確認個人／家庭單位、跨年定義與可得時間；必要時處理價格年度差異 |
| 社經與保障 | 家庭收入、就業、公私保險 | 補充資源與醫療可近性；家庭數值須正確連回個人，保險以預測前狀態為準 |
| 生活習慣（選配） | 吸菸、飲酒、身體活動 | 官方報告確認有相關調查領域；部分早年缺題或問法不同，非保證全期核心特徵 |

特徵存在性的來源為 S4–S6；是否能作無洩漏的全期預測輸入仍待原始字典與資料驗收。個人識別碼、家庭識別碼、調查權重及未來年度資訊不作一般模型輸入。

### 標籤與切分

- 初步標籤：在定義完整的結果年度內，至少一次有效住院事件為 1；確認有完整觀察且無事件才為 0。未訪、部分追蹤或事件不明不能直接補成無住院。
- t 年自評健康／診斷若實際訪問在 t+1 年，不能直接用來預測 t+1 全年住院。可改用更早的可得測量或調整觀察／預測期間，但須先固定任務。
- t 年住院診斷／支出可作歷史候選；t+1 年住院診斷、住院費、出院狀態與是否再住院等不得用作輸入。
- 長期同人追蹤意味各年列並不獨立。按年份切分是必要條件；同一人跨期可對應「已知受訪者的未來風險」，不等於對全新受訪者的泛化。推論與不確定性要處理個人／家庭內相依。
- 保留前處理、採樣、特徵選擇與門檻只使用允許訓練／驗證資料的規則；測試集不決定年份、模型或特徵。
- 2014 前後無法對齊的特徵，優先考慮排除該特徵以保留長期序列；若縮短年份，須先確認仍足夠建立舊期／新期／驗證／測試。不能為了保留年份將不同定義硬接。
