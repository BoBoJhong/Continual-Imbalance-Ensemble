# 破產預測三階段流程圖說明

更新日期：2026-10-12。範圍只涵蓋破產預測，配合目前三張主圖；分類器與 FS 在圖面使用概括名稱，具體方法留在實作說明及方法表。前三節已依最新圖面重寫為論文方法章用稿，統一納入 AUC、F1-score、Recall，並區分分類器選擇、集成選擇與分類門檻；不宣稱未驗證的分類器優越性。

## 第一階段：基準分類器比較與選擇

第一階段旨在比較不同分類器、訓練資料範圍及採樣策略在破產預測上的表現，建立後續集成與特徵選取實驗的基礎。研究以公司年度財務資料為觀測單位，使用資料集提供的公司最終存續／破產狀態作為分類標籤，並將破產類別定義為正類。候選分類器依模型類型分為傳統機器學習與深度學習兩類，具體算法與參數另於實驗設定表說明。

模型訓練分為 Old、New／Fine-tune 與 Retrain 三種策略。Old 使用歷史資料建立模型，用以評估歷史資料所學得的分類規則對較晚期間資料的適用程度；New／Fine-tune 使用新營運資料建立模型，用以評估近期資料所提供的分類資訊；Retrain 則合併歷史與新營運資料後重新訓練，作為同時使用兩個期間資料的比較基準。本研究的 New／Fine-tune 指新資料模型分支，訓練資料使用方式依上述定義執行。

資料先依實驗設定劃分訓練、驗證與測試用途，再進行前處理及採樣。前處理所需的統計量僅由對應的訓練資料估計，驗證與測試資料套用固定後的轉換。採樣策略包括不採樣、低採樣、過採樣及混合採樣，且僅作用於訓練資料；驗證與測試資料維持原始類別分布。分類器類型、訓練策略與採樣方式構成平行實驗設定，以比較不同設定下的分類表現。

依研究設計，候選分類器的比較與後續分類器選擇使用驗證資料及預先指定的選擇準則，分類門檻亦由驗證資料決定。選定分類器種類及相關設定後，固定設定並於獨立測試資料評估。後續兩階段使用選定的分類器種類，分別研究集成方式及特徵選取的影響；此處的選擇對象為分類器算法或模型種類，各階段的模型仍依對應資料與實驗設定重新訓練。

最終評估採用 AUC、F1-score 與 Recall，以 AUC 為主要指標。F1-score 綜合反映破產類別的 Precision 與 Recall；Recall 則表示實際破產樣本中被模型正確辨識的比例，用以評估少數類別的偵測能力及漏判情形。三項指標共同呈現模型的區分能力與破產類別辨識表現，測試資料不參與分類器選擇或門檻調整。

第一階段既有破產實驗以 1999–2014 年資料設定 15 組 Old／New 年份邊界，Test 固定為 2015–2018 年；內層驗證由各訓練年份內抽取約 20% 資料。此設定應與後兩階段的固定年份驗證方式分別說明。

## 第二階段：選定分類器之 Old／New 集成比較

第二階段使用選定的分類器種類，建立由歷史與新營運資料分別訓練的模型池，探討不同資料期間及採樣策略所形成模型的集成表現。分類器種類在本階段固定，使比較重點集中於 Old／New 模型組成與集成方式。

固定年份設定以 1999–2011 年作為 Old 訓練期間，2012–2014 年作為新營運期間，2015–2018 年作為 Test。其中 2014 年保留作驗證，因此 New 模型實際使用 2012–2013 年資料訓練。2014 年資料經固定種子的分層切分，分為互不重疊的 DSEL 與 Calibration 子集；DSEL 用於動態選擇時的局部分類能力估計，Calibration 用於靜態候選選擇及分類門檻決定。兩個子集均不加入模型池的訓練資料。

資料完成分區後，補值與縮放僅在 Old 訓練資料上擬合，並將相同轉換套用於其餘分區。Old 與 New 訓練資料各自採用低採樣、過採樣與混合採樣，分別訓練三個模型，形成包含三個 Old 與三個 New 的六模型池。六個模型使用同一分類器種類，但因訓練資料期間及採樣方式不同而分別建立。

集成方式分為靜態集成、動態分類器選擇（Dynamic Classifier Selection, DCS）與動態集成選擇（Dynamic Ensemble Selection, DES）。靜態集成比較由二至六個模型組成、且至少包含一個 Old 與一個 New 的混合子集；依模型數分別有 9、18、15、6 與 1 種，共 49 種組合。各組合以成員模型的預測機率等權平均產生集成機率，另以全部 Old、全部 New 及完整六模型等權集成作為控制組。DCS 依待預測樣本鄰近區域的分類能力選擇單一分類器，DES 則選擇分類器集合；兩者均使用完整六模型池及獨立 DSEL。

依目前執行協定，靜態候選依 Calibration 的平均精確率（Average Precision, AP）排序選擇，各方法的分類門檻則依 Calibration 的 F1-score 決定。候選及門檻固定後，才於 Test 產生預測並計算 AUC、F1-score 與 Recall。AUC 維持主要報告指標，F1-score 與 Recall 以破產類別為正類，使用相同的固定門檻計算。結果同時保留整體測試期間及各年度表現，以觀察不同期間的分類表現與少數類別偵測能力。

Retrain 定位為使用 Old 與 New 合併資料重新訓練的獨立比較基準，不納入六模型池。同協定 Retrain 的結果應另於比較表呈現，以保持 Old／New 模型池及 49 種混合組合的定義一致。

## 第三階段：特徵選取對集成分類器的影響

第三階段固定使用選定的分類器種類，研究特徵選取對破產預測集成模型表現的影響。資料分區、模型池組成及集成方式維持與未進行特徵選取的集成設定一致，使比較重點集中於輸入特徵集合的改變。流程圖以 Filter、Wrapper 與 Embedded 三類概括特徵選取策略，具體算法及保留特徵數另於方法表說明。

Filter 依特徵與分類標籤之間的統計關聯評分進行選取；Wrapper 透過分類器的反覆擬合或評估搜尋、刪減特徵；Embedded 利用模型訓練形成的係數或重要性進行選取。三類策略為平行設定，並非依序施作。各設定均獨立完成特徵選取及後續模型訓練。

資料處理順序為前處理、特徵選取、採樣與模型訓練。補值、縮放及特徵選取僅在 Old 訓練資料上擬合，再將固定的前處理轉換及選定特徵一致套用於 New、DSEL、Calibration 與 Test。特徵選取在採樣前完成，使選取程序使用原始訓練資料分布；採樣則僅作用於特徵選取後的 Old 與 New 訓練資料。驗證與測試資料維持原始類別分布，並使用相同的特徵欄位及排列順序。

完成特徵選取與採樣後，各設定均重新訓練三個 Old 與三個 New 模型，再分別執行靜態集成、DCS 與 DES。模型重新訓練可確保其分類規則建立於對應的特徵空間。DSEL 用於動態選擇，Calibration 用於靜態候選及分類門檻決定；驗證決策固定後，再於 Test 計算 AUC、F1-score 與 Recall，以 AUC 為主要指標。

特徵選取結果以未進行特徵選取的集成結果作為對照，於相同隨機種子、相同測試樣本及固定方法下比較三項評估指標。分析除觀察 AUC 與 F1-score 的變化，也檢視 Recall 是否維持或提升，以評估減少特徵後對破產少數類別偵測能力的影響。若特徵選取使驗證階段選出的靜態組合改變，該結果應另列為整體選擇政策的比較，不能將表現差異全部歸因於特徵刪減。研究不預設特徵選取必然改善分類表現。

## 為何後兩張圖沒有 Retrain

後兩張主圖描述 Old／New 集成模型池的內部流程。Old 與 New 各自以三種採樣建立三個模型；Retrain 則使用 Old＋New 合併資料重新訓練，是獨立的比較基準，不是原本六模型池的成員。將 Retrain 加入模型池會改變模型數與組合範圍，不能繼續沿用原本六模型、49 混合子集的定義。

若圖的用途是完整實驗比較，Retrain 應作為平行的 baseline 支線，使用相同資料可用範圍與 Test 評估，與集成結果在表格中比較。目前最新固定年份 Phase 2／3 runner 僅建立 Old／New 模型，沒有同協定 Retrain；舊 Phase 1 的 Retrain 分數不能直接當成已完成的同協定對照。這項基準比較仍需先對齊協定並補執行，故本次不在後兩張圖新增已完成 Retrain 的節點。

## 第二、三階段的實際資料分配

| 分區 | 年份 | 用途 |
|---|---|---|
| Old-fit | 1999–2011 | 訓練 Old 模型；擬合前處理與第三階段特徵選取 |
| New-fit | 2012–2013 | 訓練 New 模型 |
| DSEL | 2014 的一半資料 | 供 DCS／DES 評估局部分類能力 |
| Calibration | 2014 的另一半資料 | 選擇靜態候選及分類門檻 |
| Test | 2015–2018 | 凍結設定後的最終評估 |

New operating 期間為 2012–2014，但 2014 已保留作驗證，因此 New 模型實際使用 2012–2013 訓練。DSEL 與 Calibration 互不重疊；主圖單一 Validation 節點是兩者的簡化表示，不能理解為同一批資料兼作兩種用途。補值與縮放擬合於 Old-fit；採樣只作用於 Old-fit／New-fit。

依最新已執行協定，Calibration 的 AP 選靜態候選，F1 選分類門檻；Test 不參與選擇。AUC 是主要**報告指標**，目前不能寫成「以 AUC 選出最佳模型」。F1-score 與 Recall 均以 failed 為正類，使用驗證階段固定的門檻計算測試表現。Recall＝TP／(TP＋FN)，表示實際破產樣本中被正確辨識的比例；F1-score 則綜合 Precision 與 Recall。

## 論文定稿前需對齊的實作與證據

上述前三節描述使用者確認的研究流程；目前最新固定年份 runner 使用 XGBoost，尚缺將第一階段驗證比較與該選擇串接的完整紀錄。不得將方法用稿中的分類器選擇流程改寫成「已證明 XGBoost 最佳」。同協定 Retrain 亦尚待補足；第一階段舊結果不得直接當成後兩階段的同條件對照。

第三階段目前實際設定為 MI／CART／SHAP／RFE，各保留 9／14 個特徵，共八種 FS 設定。MI 屬 Filter，RFE 屬 Wrapper，CART 使用樹模型重要性；SHAP 為模型解釋後的特徵排序，應在方法表獨立交代，不能僅因三類概括圖就將其當成純 Embedded。具體 FS 機制可參閱[官方特徵選取文件](https://scikit-learn.org/stable/modules/feature_selection.html)。

補上正式方法表時，應列出實際分類器及後端、超參數、採樣算法及參數、分類器選擇準則、隨機種子與執行來源。本稿未新增實驗結果、統計顯著性或前瞻一年期破產事件預測的主張。研究規格與證據限制見 `docs/研究方向.md` 的 C44／C46／C47。
