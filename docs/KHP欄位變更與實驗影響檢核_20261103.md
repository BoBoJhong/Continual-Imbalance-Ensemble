# KHP 第一期欄位變更與實驗影響檢核

查核日期：2026-11-03。用途：判斷 KHP 2008–2018 能否作為「前一年資訊預測次年住院」的舊期／新期、集成與特徵選擇資料。

## 判斷與驗收範圍

**已確認存在實質的問法、編碼、題目涵蓋與樣本變更。KHP 可保留候選，但尚不能把全期候選特徵直接合併，也不能宣稱已找到全期穩定的特徵表。**前輪「特徵種類符合」僅指含有所需概念，不等同於跨年度測量一致。

本輪核對官方文件與原始研究，未取得第一期各年完整代碼簿、個體檔及住院事件檔，因此不是逐年原始欄位差異驗收，沒有計算缺失率、標籤一致率或 AUC／AP 影響幅度。KHP 預測實驗尚未執行，本輪沒有待重跑的 KHP 結果。

分析單位擬為「受訪者 × 特徵年度」，連結同一人完整結果期間的住院有無。疾病與醫療利用事件須各自彙總，不能直接作多對多合併。

## 改版年份有未解差異

S1 頁 69 說疾病碼 2012 起採 KCD；S2 頁 92 說 2014 年調查起採 KCD。S3 附錄表 A1 也分列不同時段碼制，但其標籤與位數不能代替官方年度碼本。因此本輪只確認「存在多種碼制，不能直接串接」，不自行指定唯一改版年度檔。

調查執行年、年度醫療利用參照年、當下健康測量年與資料釋出年須分開；來源差異可能涉及年度定位或資料版本，但尚未證明原因。正式實作須以選定版本的第一期碼本解決。不能把 2014 前後數值跳動直接稱為自然健康漂移。

S2 當時主要描述第二期制度；本文不將其第二期年齡門檻、疾病清單、檔名或年度組合規則當作第一期欄位合約。

## 對既有實驗框架的影響

- **Old／New**：若 New 與 Test 共享問卷／碼制，新模型優勢可能部分來自測量相容性，不能全部歸為近期模型更能掌握真實健康變化。
- **FS**：未對齊病種、疾病數或缺題旗標可能因辨識年代而取得高排名；不直接解讀為臨床風險因子。
- **集成與採樣**：可以運行不等於輸入可比較；採樣、加權及集成不會自動修復不同定義或資訊洩漏。
- **標籤**：目前未證明「至少一次住院」二元定義本身跨年改變。需獨立核對事件範圍（日間／中醫等納入規則）、開始／結束日期、完整追蹤與零事件認定，不能因問卷題數不同就宣布標籤失效。
- **跨領域解釋**：同一演算法框架仍可比較，但不能把測量變更直接解讀為醫療領域本質或全部真實漂移，也不以跨任務原始 AP 高低判難度。

## 特徵與年份處置建議

1. 優先驗收年齡、性別、教育／婚姻共同粗類別，以及依事件彙整的既往住院／急診／門診與口徑一致的費用。收入、保險、自評健康、共同疾病群另查全期問法、單位、合法值與資訊時間。
2. 未可靠對齊的總慢性病數、原診斷碼、斷續附加題與僅部分年份的醫療體驗先不收。未問／不適用／拒答不能全部混為零；不存在的測量不能靠補值視為已測。
3. 先嘗試較長期間的共同特徵，不先承諾縮成 2014–2018 就穩定。若最終只有這五年可用，最多四組次年轉換，Old／New 的跨度及驗證／測試配置都須重估，不能仍聲稱十組年度任務。
4. 選年與特徵規則在模型測試前固定；不從 Test 成績選起始年。未來住院診斷／費用、未來退出狀態及個人／家庭 ID 不作一般特徵，ID 留作連結與相依性處理。
5. 若連住院標籤或資訊時間也無法統一，就不讓 KHP 進入正式主實驗。現階段保留候選，不宣稱全期可直接用。

## 原始資料驗收尚缺什麼

- 選定版本各年欄名、定義、型態、合法值、特殊碼、調查對象、訪問日與參照期對照；明列不可解的映射。
- 主檔一人一年唯一性、事件彙整、ID 連結覆蓋、相鄰年配對數及有效標籤數；缺事件列不能自動當完整零事件。
- 定義與時間通過後，再看改版前後缺失／特殊碼比例、共同疾病計數及不合理跳動；有跳動不直接判真實或人工漂移。
- 固定 cohort、輸入白名單、結果期與 Old／New／驗證／Test 後才啟動原框架。這些是資料驗收，不是新增模型或另開年度特徵實驗支線。
