## 目前最有力的三個結論

### 1. New-side model pool 在未來測試期更有效

跨 15 個年份切割，New models 相較 Old models 在多個採樣策略下皆顯著較好：

- `New_under > Old_under` AUC two-sided p = `0.00006104`
- `New_under > Old_under` F1 two-sided p = `0.00061035`
- `New_under > Old_under` Recall two-sided p = `0.00065331`
- `New_hybrid > Old_hybrid` AUC two-sided p = `0.00012207`

這支持 weighted ensemble 中提高 New models 權重的合理性。

### 2. Drift-aware boundary + weighted ensemble 有助於提升 F1 / Precision

目前 final-test 最佳設定為：

- Boundary: `ValROSS_2009`
- FS: enabled
- Weight: `w_old=0.05`, `w_new=0.95`
- F1: `0.243154`
- Precision: `0.177316`

相對 fixed equal baseline：

- F1 +`0.051638`
- Precision +`0.059901`

跨 15 個年份邊界的 validation-selected weighting 也顯著優於 equal weighting：

- FS F1 two-sided p = `0.000854`
- no-FS F1 two-sided p = `0.035339`
- FS AUC two-sided p = `0.000610`

### 3. Feature selection 的穩定性以 r80 較佳

以 selected feature set 的 Jaccard similarity 來看，`r80` 明顯比 `r50` 穩定：

- `old + mutual_info`: `0.772232` vs `0.429518`
- `old + rfe`: `0.756262` vs `0.521625`
- `old + shap`: `0.826027` vs `0.667173`
- `new + mutual_info`: `0.818744` vs `0.667732`
- `new + shap`: `0.787838` vs `0.736477`
- `new + rfe`: `0.741645` vs `0.536607`

這些比較的 directional p-value 皆小於 `0.05`，多數 two-sided p-value 也遠小於 `0.05`。

## 目前最適合收斂的研究敘事

目前研究可以收斂為：

> 本研究在非平穩且類別不平衡的破產預測中，發現固定 Old/New 切割與等權集成不足以反映資料分佈變化。透過 validation-based drift boundary selection，可將 Old/New 邊界調整至 2009；再結合 New-dominant weighted ensemble 與適度 feature selection，可提升 F1 與 Precision，且 validation-selected weighting 跨 15 個年份邊界顯著優於 equal weighting。統計檢定進一步支持 New-side model pool 在未來測試期顯著優於 Old-side model pool，而含 SHAP 的特徵穩定性分析則顯示 r80 feature selection 在跨年份切割下更穩定。10-seed raw Wilcoxon 也補強了 Bankruptcy 結果的重現性。
