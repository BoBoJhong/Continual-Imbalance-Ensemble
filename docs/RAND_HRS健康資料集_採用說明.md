# RAND HRS 健康資料集採用說明

擬採用美國 Health and Retirement Study（HRS）的 RAND 縱貫整合資料，作為論文的健康領域資料集。以同一位受訪者本次訪問的健康狀況與既往住院紀錄，預測到下次訪問前是否住院，並沿用破產資料的舊期／新期模型、集成與特徵選擇比較框架。HRS 約每兩年訪問一次，因此本任務為跨訪問期間的未來住院預測。

**2026-11-03 存取與執行方式更正：**重新實際開啟官方產品頁，未登入時只有登入／註冊提示，沒有個體資料下載連結。本輪另查到官方 [AI 與 LLM 使用政策](https://hrsdata.isr.umich.edu/data-products/ai-llm-use-policy)（頁面標示更新 08/04/2026）：禁止將 HRS 個體資料提供給 LLM，範圍包含 RAND 與 Gateway 版本；允許以公開碼本撰寫分析程式，以及分享不含個體資料的模型係數／彙整統計。因此，本候選仍可供研究者自行取得資料及執行分析，但不能沿用「把原始檔上傳 AI，由助理讀取並試跑」的流程。先前對話請使用者上傳檔案或放入本專案供助理讀取的建議撤回；個體資料應留在 AI 工具無法存取或索引的位置。

## 資料概要

| 項目 | 內容 |
|---|---|
| 來源 | 美國密西根大學 HRS；由 RAND 製作跨期整合版本，屬官方公共研究資料，須註冊 HRS 帳號下載 |
| 性質 | 美國中高齡受訪者及配偶的長期追蹤調查，包含健康、疾病、醫療利用及社經資訊，可用個人識別碼連結不同波次 |
| 年份 | 擬使用 2000–2016，每兩年一次，共九次訪問，可建立 2000→2002 至 2014→2016 共八組前後期預測 |
| 規模 | 已核對的 2022 V1 碼本中，2016 年有 20,737 筆有效住院回答；正式跨期配對與篩選後人數仍須計算 |
| 任務 | 根據本次訪問資訊，預測同一位受訪者到下次訪問前是否有至少一次過夜住院，期間通常約兩年 |
| 特徵 | 初步規劃 14 個核心特徵：年齡、性別、自評健康、八類慢性病，以及過去住院有無、次數與住院晚數 |
| 正例比例 | 上述 2016 單期有效回答中，住院者 5,214 人，約占 25.14%，負：正約 3：1；不是正式配對樣本的比例 |

八類慢性病為高血壓、糖尿病、癌症、肺病、心臟病、中風、精神心理問題及關節炎；採用當期可得的疾病回答，避免使用後期回答回改的歷史欄位。

資料來源與存取方式：[HRS 官方資料頁](https://hrsdata.isr.umich.edu/node/38308)、[RAND 官方整合資料說明](https://www.rand.org/health/surveys/hrs/hrs-data.html)。欄位、住院期間與規模依據：[RAND HRS 2022 V1 官方碼本](https://hrsdata.isr.umich.edu/sites/default/files/documentation/other/1758643082/randhrs1992_2022v1.pdf)，自評健康、Hospitalization 及 Doctor-diagnosed Conditions 章節。

## 為何要用

1. **有明確的未來預測目標。** 使用本次訪問資訊預測其後至下次訪問間的住院事件，例如用 2000 年資訊預測 2000 至 2002 年兩次訪問之間是否住院。

2. **可長期追蹤同一個人。** 同一位受訪者可跨多個波次連結，適合建立健康狀況與後續結果的時間順序。

3. **有官方跨期整合版本。** RAND 已提供一致命名、變數建構規則及跨期差異說明，便於固定共同特徵與重現前處理。初步選取 2000–2016，以避開已記載的較後期疾病問法調整；仍須核對實際下載版本。

4. **具有類別不平衡。** 碼本範例中住院者約占四分之一，可研究少數類別辨識；不平衡程度較溫和，正式比例與各期正例數須以配對資料確認。

5. **可保留跨領域比較。** 健康資料可沿用原有模型、集成與特徵選擇規則，時間切分單位改為訪問波次，檢驗方法在不同任務中的表現，不預設新期或集成一定較好。

## 目前進度

已完成官方整合資料說明與 V1 碼本的初步查核，確認住院標籤、候選核心特徵及其跨期建構規則，並提出 2000–2016 的使用範圍。尚未下載個體資料、建立正式跨期配對樣本或執行模型實驗。

下一步由研究者自行登入／註冊官方帳號、核對並接受適用條款後取得資料，在 AI 無法存取或索引的位置執行分析。助理可依公開碼本撰寫程式；研究者自行完成版本、核心欄位、資訊時間、配對樣本與分區驗收後，只分享不含個體列、ID 或原始值的彙整品質與效能結果。本輪選定 XGBoost 作為待執行的初步分類器，但未取得資料、未完成試跑程式，沒有 AUC／AP／F1 等實驗結果。

限制：研究對象主要為中高齡人口及配偶；追蹤期間約兩年，不能稱為「明年住院預測」。資料仍有新增樣本、死亡與失訪，不能保證同一批人全期完整，也不能以未受訪直接判定沒有住院。單期有效人數不等於跨期配對後人數。若未使用調查權重，結果僅代表研究樣本。

目前數值與欄位查核以 2022 V1 碼本為依據；官方資料頁已列 V2，正式使用前須確認實際版本差異。本方案有明確核心欄位與防洩漏規則，尚未完成原始資料驗收，也不宣稱所有欄位皆無跨期變動。

研究定位補充：住院事件可作未來風險預測，也可用來評估分批更新；但同人跨期、病患狀態改變與多年資料本身，都不證明模型需要持續學習。目前固定舊期／新期模型及集成比較，能回答新舊資料與模型搭配的問題；若要主張長期持續更新有效，須另有按資料與標籤可得時間逐期更新、評估的證據。HRS 的漂移程度、更新收益與實際照護效益目前皆未驗證。
