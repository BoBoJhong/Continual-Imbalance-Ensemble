# 目前研究結論整理

更新日期：2026-09-08

本文件只整理目前可由版本化結果直接支持的結論。完整圖表與口頭報告材料見
`docs/PROFESSOR_PROGRESS_REPORT.md`，方法與限制稽核見
`docs/EXPERIMENT_VALIDATION_REPORT.md`。

## 目前最穩健的結果

2009–2018 十個年度 rolling walk-forward 共產生 33,636 筆 out-of-time
預測。pooled 結果如下：

| 方法 | AUC | F1 | Recall | Precision |
|---|---:|---:|---:|---:|
| New_under | 0.8403 | 0.3287 | 0.3673 | 0.2975 |
| DAWCE_AUC | 0.8237 | 0.3275 | 0.3392 | 0.3165 |
| AdaptiveChoice_AUC | 0.8221 | 0.3283 | 0.3652 | 0.2982 |
| Retrain_under | 0.8116 | 0.2943 | 0.3146 | 0.2764 |
| Equal6 | 0.7971 | 0.2830 | 0.3553 | 0.2351 |

目前最合理的主結論是：**近期資料訓練的 `New_under` 是強基準；自適應
加權能避免等權混入弱舊模型，但尚未證明普遍優於該強單模型。**

十個年度的 paired Wilcoxon 檢定共 16 項比較，採 Holm 校正。只有
AdaptiveChoice_AUC 相對 Equal6 的 AUC 差異通過校正
（平均年度差 +0.0327，raw p=0.001953，Holm p=0.031250）。相對
`New_under` 的 AUC、F1、Recall 與 Precision 均不顯著。

## 公平消融與特徵選擇

固定相同候選模型、資料切割與前處理後，no-FS 消融的 `New_under`
test AUC/F1 為 0.8498/0.2143，DAWCE_AUC 為 0.8361/0.1878，Equal6
為 0.8086/0.1611。這表示目前 DAWCE 的主要價值是優於等權平均，而不是
取代所有強單模型。

特徵穩定度結果顯示，多數 Old 或 New scope 下 r80 的平均 Jaccard 高於
r50；例如 New mutual information 為 0.8187 對 0.6677。`old_new` scope
在不同邊界下實際使用相同的 1999–2014 合併資料，因此其接近或等於 1 的
Jaccard 是設計結果，不能當成額外的跨時間穩定性證據。

## 只能作輔助解讀的結果

- 既有 10-seed 檔案採 LightGBM/block-CV，並非主 XGBoost rolling
  流程的完整重複。seed 傳遞程式已修正，但舊 CSV 在重跑前仍只可作歷史
  輔助結果，不可用來宣稱主結論已完成多種子重現。
- Phase 2 的 `Static oracle best` 是依 Test 指標事後挑出的上界，不能與
  可部署的 validation-selected DES/DCS 作無偏顯著性宣稱。
- `FPR + r × FNR` 是盛行率中性的條件錯誤分數，不是 expected cost。
  部署成本應加入正類盛行率與實際 FP/FN 金額。
- 目前證據主要來自美國企業破產資料；Stock 與 Medical 尚未形成與主流程
  完全對齊的外部驗證。

## 可報告與不可報告的措辭

可以說：「rolling 結果支持近期資料模型是強基準，validation-guided
weighting 在 AUC 上優於 Equal6。」

不可說：「DAWCE 已顯著優於所有基準」、「靜態方法已無偏地顯著優於
DES/DCS」、「10-seed 已證明主實驗完全可重現」或「目前成本曲線就是實際
部署期望成本」。

## 下一步

1. 以同一 XGBoost rolling protocol 執行完整 10+ seeds，保存逐 seed、
   逐年度預測與失敗紀錄。
2. 將閾值調整、機率校準與超參數選擇全部限制在 validation period。
3. 補 PR-AUC、bootstrap confidence interval 與 effect size。
4. 在 Stock/Medical 或另一個公開財務資料集重複同一 protocol。
5. 若要作部署成本結論，加入盛行率與可辯護的金額成本情境。
