## 文件維護方式

新結果先綁定 run、協定、seed 集合與來源，再更新研究方向。部分 seeds 的匯出表保持快照身份；另建新快照時記錄來源，避免覆寫歷史表。數值結果由擁有該結果的實驗／分析腳本產生。論文整合另依明確指示進行。
