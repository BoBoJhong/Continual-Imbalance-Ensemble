# RAND HRS：建議取代 KHP 的健康資料候選

查核日期：2026-11-03。使用者要求重新找較容易建立可靠實驗的資料。本輪優先確認官方跨期整合、同人長期追蹤、明確後續事件及核心輸入，不再僅因原始資料包含所需概念就推薦整個年度範圍。

## 建議與必要取捨

建議使用 **RAND HRS Longitudinal File**，以 **2000–2016 九次訪問（Wave 5–13）**為初步範圍，建立八組相鄰訪問預測。資料主要是美國中高齡人口及配偶，每兩年左右訪問一次，**因此任務需明確改為「本次訪問資訊預測到下次訪問前是否住院」；這是候選任務，不默認使用者已核准更改原來的次年任務**。

官方 RAND 已整合欄名及建構規則，並記錄跨期差異，較適合從固定核心欄位起步。此處推薦理由是有較清楚的整合產品與可界定範圍，不宣稱整份 HRS 的所有變數都從未變動、完全無缺失或全體受訪者持續不變。

## 已核對的核心與時間窗

| 用途 | 欄位家族（w 為波次） | 候選規則與證據定位 |
|---|---|---|
| 年齡 | `RwAGEY_E` | 訪問結束時年齡，與基準資訊時點對齊；S2 Age（約印刷頁 140–145），官方建議結束時年齡 |
| 性別 | `RAGENDER` | 官方個人背景欄；S2 Gender，1／2 合法類別 |
| 自評健康 | `RwSHLT` | 1 Excellent 至 5 Poor，保留特殊缺失；S2 頁 250，除 Wave 1 補值例外外有一致建構說明，本建議避開 Wave 1 |
| 八類慢性病 | `RwHIBP`、`RwDIAB`、`RwCANCR`、`RwLUNG`、`RwHEART`、`RwSTROK`、`RwPSYCH`、`RwARTHR` | 採當期回答及必要的當期 Q 問法旗標；S2 頁 395–397 說明 Wave 5–13 的否認既往紀錄後追問當期疾病情形規則 |
| 既往住院 | `RwHOSP`、`RwHSPTIM`、`RwHSPNIT` | 分別為參照期有無過夜住院、次數、晚數；S2 頁 257–262。限制相鄰有訪問的配對以避免多年漏訪區間混入 |
| 結果標籤 | `R(w+1)HOSP` | 有過夜住院為 1，無為 0；未知／拒答／缺失不當零。已連續受訪者的結果期是上次訪問至本次訪問，通常約兩年，不保證恰好 730 天 |

以上為 14 個核心特徵概念（2 個背景＋1 個自評健康＋8 個疾病＋3 個住院）；合法值、缺失與版本核對後才形成最終模型欄位。此設計不需把整套原始疾病分類碼跨年拼接。第一版不加入醫療支出、認知、睡眠或其他有不同涵蓋／補值規則的擴充欄位。

### 已事先排除的風險

- **不用未來修訂的疾病歷史**：S2 頁 438–439 明示 `Rw...E`（ever had）會因後續否認而回改之前波次。預測輸入不直接用這組 E 欄或 `RwCONDE`，改從當期原始回答及 Q 旗標確認。特殊值 3／4 依 Wave 5–13 官方定義處理；其他未辨明值保留待核。
- **避開 Wave 14 起的疾病問法更動**：S2 頁 396 記載否認既往病史的選項與跳題規則在 Wave 14 改變。本候選範圍在 Wave 13（2016）結束，不將 2018 之後自動接入。
- **不混用早期住院參照期**：S2 頁 261 記載 Wave 1 及 2A 為前 12 個月；其他波次為上次訪問以來、新受訪者則為兩年。本建議由 Wave 5 開始，並用連續配對的後一期標籤。
- **不宣稱全期固定人數**：HRS 有新增 cohort、死亡及失訪，必須用個人 ID 連結。可先定義基準 cohort 並使用其後有效配對，不靠「未來九次全部留下」才入組；有效樣本數仍須實算。
- **死亡與未訪不當無住院**：初版若只用相鄰 Core 訪問，推論族群限於可配對者；死亡與 Exit 訪問需另定義觀察終點，不混成完整兩年陰性。

## 規模與類別不平衡的文件證據

S2 的 `RwHOSP` 次數表（印刷頁 260–261）列 Wave 13：0.No 為 15,523、1.Yes 為 5,214，共 20,737 筆有效回答；5,214／20,737＝25.1435%。這是 **2022 V1 碼本中的 2016 單期、未加權住院回答**，不是本研究基準 cohort、跨期配對或抽樣後的正例比例。約四分之一為正例，不平衡程度較溫和，不能宣稱與原 KHP／MEPS 相同。

該證據確認有萬人級的單期有效標籤，不保證固定同一萬人能連續留存，也不保證每一期配對後都有一萬人。

- 尚未註冊帳號、接受資料條款或取得個體資料，未執行模型。這是有具體核心設計的資料推薦，不是完成本地輸入驗收。

## 與原研究框架的關係

Old／New、採樣、集成、FS 及驗證選型可保留同一算法規則，但期間單位由年度改為訪問波次。八組相鄰配對足以提出候選分區，正式分區仍需按有效樣本量與結果完成時間固定。這個變更影響預測期間，必須在研究說明明列，不能仍稱「明年住院」。

下一步的實際依賴是取得研究者自己的公共資料下載權限與指定版本資料，完成版本差異、配對數及時間驗收；不需要先擴充到其他候選或加入新模型。

## 持續學習適用性補充（2026-11-03）

住院標籤是每個未來期間的事件，可在同一人身上依序為 0、1、0，仍是有意義的風險預測。固定二元目標可用於分批更新，不需要新增疾病類別才能研究持續學習；同人追蹤也不是持續學習的必要條件，它在本任務的價值是連結觀察期與後續結果。

病患年齡／疾病或特徵分布變化，不能直接推論條件風險關係已變或模型必須更新。固定模型也能根據病患新的年齡與健康輸入改變預測。持續更新的研究問題是：新資料進入後，更新模型或模型池是否能在後續期間帶來額外收益，或在限制的記憶／運算資源下維持效果。

HRS 約兩年一批、候選期八組轉換，可用於離線批次更新的可行性研究；更新次數有限且有約兩年結果等待、失訪與資料釋出延遲等可得性問題，不適合直接宣稱高頻即時適應。尚未證明 HRS 舊模型會跨期退化或更新一定改善。正例約 25% 的碼本例也僅支持較溫和不平衡，不代表極端稀有事件。

現有固定 Old／New、集成與 FS 架構可定位為「時間變化下的新舊模型組合比較」。若主張逐期持續學習效益，需要按標籤可得時間先評估先前預測，再更新，並比較未更新模型及允許範圍內的既有更新／重訓策略；若主張知識保留或抗遺忘，再對應評估保留能力。這是方法定位與證據需求，不自動新增 Fine-tune、五折或其他使用者未要求的正式實驗。

原始方法來源：Lopez-Paz 與 Ranzato（2017）[GEM，Section 2](https://proceedings.neurips.cc/paper_files/paper/2017/file/f87522788a2be2d171666752f97ddebb-Paper.pdf)支持依序學習與保留能力的評估；Schuessler 等（2025）[臨床時間驗證原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC12219301/)，Model longevity／Progression analysis，直接比較固定與逐年更新，並觀察到舊資料仍可有效。前者不是醫療實證，後者不是 HRS；均不能當作本資料的更新收益證據。

因此，HRS 保留為未來住院／跨期比較候選；持續學習必要性與效果尚待證實，不因「資料較整齊」就宣稱已驗證其對研究主題的價值。
