## 標準方法與版本

- **KNORA-E**：若沒有模型在全部近鄰答對，依標準規則縮小鄰域再選；不再立即平均全池。
- **KNORA-U**：局部答對樣本數決定影響程度，不再把所有至少答對一筆的模型等權平均。
- **OLA／LCA**：使用官方實作，以 `selection_method=best` 選擇最有能力的分類器；平手選最小槽位索引。LCA 的類別鄰域依真實 DSEL 類別定義。
- 固定 k=7、DFP=False、with_IH=False；DES 採官方 soft voting，DCS 採官方 `predict_proba`。
- **機率慣例**：DESlib 0.3.7 的 KNORA-U soft voting 會對加權平均分數作 softmax；本專案保留此官方版本行為，沒有另改成除以權重總和。全模型預測同類時，保留 DESlib 的全池平均機率捷徑。
- sklearn 1.8 移除了 `_validate_data`；相容層僅將此資料檢查轉接到 `validate_data`，沒有覆寫 competence、selection 或 voting。

方法來源：[KNORA-E 官方文件](https://deslib.readthedocs.io/en/latest/modules/des/knora_e.html)、[KNORA-U 官方文件](https://deslib.readthedocs.io/en/latest/modules/des/knora_u.html)。本輪數值以 manifest 鎖定的 DESlib 0.3.7 為準，不能把官方 latest 文件當成每個版本機率實作完全一致的保證。原始方法文獻 Ko、Sabourin、Britto Jr. (2008), *From dynamic classifier selection to dynamic ensemble selection*, Pattern Recognition 41(5), 1718–1731，DOI [10.1016/j.patcog.2007.10.015](https://doi.org/10.1016/j.patcog.2007.10.015)，已列於研究方向的核心文獻。

## 特徵選取與比較矩陣

九種設定：no-FS；MI、CART、SHAP、RFE 各保留 50%／80%，即 9／14 個特徵。

所有 supervised FS 只擬合 Old-fit 的原始訓練樣本與標籤，且在 under／over／hybrid 採樣前執行。MI／CART／RFE 使用對應 seed；SHAP 使用訓練資料上 LightGBM 的精確樹貢獻值（排除 bias），不以驗證／Test 重新計算特徵排名。同一個設定內六模型共用該特徵集合與 Old-fit 前處理。

每個設定包含：六單模型、Old3／New3／Equal6、49 個混合子集（9／18／15／6／1）、四個標準動態方法，及 Calibration AP 選出的 `ValidationSelectedStatic`，共 **63 個方法**。各報 pooled Test 與四個年度指標，共 **315 列／seed／FS 設定**。

所有方法門檻均只由 Calibration 的 0.01–0.99 F1 格點選定，再固定至 Test。靜態最佳候選只按 Calibration AP 排名；不得從 Test 表事後挑最高者作無偏成效主張。

`fs_paired_differences.csv` 只比較同 seed、同固定方法、相同 Test 的 FS／no-FS 差值。`ValidationSelectedStatic` 的模型組合可隨 FS 改變，另放 `fs_selected_policy_differences.csv`，屬整體選模政策比較，不能稱為純 FS 效果。

## 舊版分數與修正版的描述性對照（2026-10-05）

舊實驗一另有不同版本：`tuned_des_rerun_20260406` 的同年份 all6 KNORA-E/U F1 為 0.1873／0.2440，phase2 DCS 表同年份 OLA/LCA 為 0.2430／0.2382，均高於本輪 no-FS 均值。這些紀錄不可混成唯一的「修正前分數」。結論是：相對舊實驗二有升有降；相對上述舊實驗一四者較低，沒有整體分數提高的證據。若要隔離修正本身的影響，需在本輪相同資料／seeds／門檻協定下重跑舊方法作配對消融。
