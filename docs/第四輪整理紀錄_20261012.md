## 驗證與限制

- 完整專案：142 項測試通過。
- 新封存契約：23 組 import 測試禁止 read_csv、to_csv、mkdir、write_text、Workbook.save、savefig、shutil.move／copy2；另 1 項核對 ZIP 所有來源雜湊。
- 23 支工具均取得正確 repository root；可定位的原輸出常數仍指向 results。
- 105 個既有函式經 root／usage 路徑正規化並排除新 mkdir 守門後 AST 一致；Excel 原建表／讀表／輸出語句順序一致，只移入明確 main。
- 新測試完整 Ruff 通過；23 支封存工具的語法與未定義名稱檢查通過。沒有為統一舊程式風格而大幅改寫。
- run_all_experiments.py --list 核對 17 支維護入口，runner bytes 不改。
- 所有原 results 檔保留原路徑、大小與修改時間；原始資料、論文正文、runner 及關鍵來源／結果 SHA-256 保持。
- 文件連結同步，研究主文件與教授報告只追加整理狀態，不改既有成效。

import 安全與語法通過不保證每份歷史輸入仍存在，亦不證明所有舊 CLI 可重新生成完整成果。舊 Excel／部分 FS 匯出已存在文字亂碼，原文封存未修造研究表。真實執行前核對來源與輸出；結果 archive／migrate 工具本輪未運行。

測試使用 .venv 的研究依賴與既存 pytest 9.0.2／Ruff 0.15.11，未更新 requirements 或安裝新研究套件。
