## 驗證結果

- 整理前核心測試：28 項通過。
- 整理後完整測試：106 項通過，包括新增的 import 隔離與 25 支封存入口路徑契約。
- Ruff：兩個共用模組、兩支現行入口與新增測試通過。
- 一鍵 runner --list：17 支維護入口全部存在。
- 固定年份、FS wrapper、完整滑動視窗三個入口的 --help 通過。
- 五個抽取函式逐一比對 AST，函式內容一致；新封存入口核對清冊中的來源雜湊。
- 原始資料、論文正文、一鍵 runner 與關鍵正式結果共 19 份檔案的 SHA-256 保持一致。
- results 目錄原有 14,695 份檔案中，只有人工維護的 README 更新導航；其餘 14,694 份檔案的路徑、大小與修改時間保持一致。這是資產保存檢查，不是全部數值重新審查。
- 文件連結查核以本輪新建／更新的導航與搬移後相對路徑為範圍；歷史正文的數字與研究快照身份保留。

測試使用專案 .venv 的 Python 與研究依賴，從既存使用者套件讀取 pytest 9.0.2／Ruff 0.15.11；沒有新增套件版本或修改 requirements。
