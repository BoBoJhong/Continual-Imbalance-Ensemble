## 共同程式與研究範圍

- 移除 DataLoader、年份切割 helper 的股票 API，以及設定中的股票資料與技術指標。
- retrain 與歷史 Phase 2／3 批次只保留破產／醫療；舊遷移、同步、統計與 Excel 工具不再派送股票。Excel 讀取混合歷史資料時只取保留領域，不改來源表。
- 合成資料工具只生成醫療資料。108 個仍存在的既有函式 AST 一致；變更函式與已移除函式列於清冊 function_review。
- 現行研究方向、入口與導航同步；歷史文件保留當時內容。來源搬移清冊的 revisions 保留範圍調整前的 SHA-256，原文 ZIP 不變。

混合資料集舊彙總、RESULT_MANIFEST、既有 run manifest 與歷史報告仍保留。它們的股票文字是歷史紀錄，不是現行入口；這次未手改混合 CSV 的股票列、研究成效數字或 thesis/THESIS_FULL.md。
