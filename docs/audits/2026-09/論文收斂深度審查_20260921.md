## 2. 阻礙論文收斂的必修項

### R1｜P1：主線與研究問題尚未跟上最完整的證據

### R3｜P1：ROSS 方法描述與實際結果來源不一致

**位置**：第 412 行候選 2003–2011；Algorithm 1；第 592 行 11 個切點、66＋6 fits；§4.4.1 第 849 行附近「New-side 模型池 AUC」。

**實際證據**：[bankruptcy_ross_validation.py](../../../experiments/phase4_drift/bankruptcy_ross_validation.py) 第 63–64、90–102、118–146 行；[候選 CSV](../../../results/phase4_drift/bk_validation_ross_candidates.csv)。CSV 有 **12 個切點（2000–2011）**。每一側呼叫 `_best_single_on_validation`，由四種 sampling 的候選單模型依 AUC／F1／Precision 排名；不是三模型機率平均後的 New-side pool AUC。2009 的 0.856780 對應 `best_new_sampling=undersampling`。

因此按目前搜尋迴圈，每個切點兩側各四個候選，即 **12×2×4＝96 次搜尋階段 fitting**；最終配置另計，不能直接沿用正文 72 次总訓練數。這是程式結構計數，不是本次實測時間。

**修法**：按產生表 4-6 的實際協定改写算法、候選範圍、排名對象與成本說明；將 k=2、固定邊界加權、rolling 版本各自標明，不以一段偽碼宣稱完整涵蓋不同版本。保留目前結果不需要重跑；若作者堅持論文描述的另一個演算法，才需要新版本重跑並另存結果。

### R4｜P1：資料洩漏及前處理版本敘述互相矛盾

**位置**：§4.1 第 723–730 行；§5.3 限制 4 第 1433 行。

§4.1 仍稱 Phase 4/5 補值使用各分割本身均值，§5.3 卻稱已修正並重跑。現行 `bankruptcy_drift_stream.py` 的 `_preprocess`（115–132 行）以 training mean 補所有分割，程式已不是 §4.1 的舊描述；然而僅看現行程式不能認證所有歷史結果都由該版本產生。相同段落「模型選擇與主要統計推論不使用 Test 標籤」也不正確：最終指標與統計比較本來就需要 Test 標籤，應限制的是選模、選參與閾值。

**修法**：對每張主要 A 結果表列來源、版本及前處理狀態；無法追溯的舊表降為歷史診斷，不能概括稱已全數修正。不同新舊 Hybrid sampling 設定須沿用 manifest 區分。B 的閾值搜尋為 0.01–0.99，A rolling 為 0.05–0.95，§4.1 不應寫成全研究同一範圍。套件版本按 run manifest 列出：新比例實驗 NumPy 2.4.2／pandas 3.0.1，不能由舊審查環境 2.4.0／2.3.3 代替。

### R5｜P1：舊統計限制已說明，但表格與貢獻仍恢復強主張

**位置**：表 4-2 第 759 行起、表 4-3 第 796 行起；§5.2.1 第 1387 行「以 p<0.001 確認」；§5.3 限制 1 第 1421 行。

15 個相依切割及 test-selected oracle 已被正文正確註明，但「顯著 ✓ 大效果」、特徵選取「顯著 ✓」與貢獻的「確認」仍讓讀者得到確認性結論。Holm 校正只處理多重比較，不能解除年度自相關；目前 B 的公司 bootstrap 與新增年度區塊也未涵蓋聯合公司／時間重抽及訓練變異。

**修法**：舊表改「描述性差異／原始 p（不作確認性推論）」並移除顯著勾選；刪除與限制相反的「確認」。Static oracle 比較不能支持指定靜態演算法優於 DES。保留效果量與完整負結果，不把 CI 跨零寫成等效。新敏感度維持探索性、未校正、多次檢視相同 Test 的限定，不為收斂追求更小 p 值。

### R6｜P1：Jaccard 的跨保留率比較存在第二層問題，引用方向也有誤

**位置**：第 341 行；§3.6.2；表 4-4；§4.7.3 第 1317 行「較佳平衡點」。

除了已承認的 105 pair 偽重複，r80 與 r50 保留的特徵數不同，未校正的集合重疊亦受集合大小影響。不能只補 split-level bootstrap，就將 r80 的較高原始 Jaccard 解釋為演算法本質更穩定。

Nogueira、Sechidis、Brown（2018）實際討論 chance correction，Table 2／Figure 2 與 Appendix C.5 指出 Jaccard 缺少該性質；不支持本文「指出 Jaccard 在小樣本高維下是可靠指標」的概括。[JMLR 原文，印刷頁 10–12、46](https://www.jmlr.org/papers/volume18/17-514/17-514.pdf)。

**修法**：校正引用；將原始 Jaccard 定位為集合重疊描述，明列集合大小混淆並刪除較佳平衡點主張。若要保留 r80 穩定性優越作核心貢獻，才補 chance-adjusted measure 與合適重抽；推薦本輪採降階處理，不新增非主線實驗。

### R7｜P1：選到邊界或零權重，不能證明漂移事件及其原因

**位置**：§2.6.2 第 375 行；第 617 行「不需預先假設飄移次數」；§4.4.0 第 845 行；§4.4.1 第 859 行；§4.4.4 第 941 行。

「2009 邊界與危機吻合」只能作事後解釋；沒有分布檢查或可識別設計，不能寫為已證明危機改變判斷標準。k=2 的 `(0,0,1)` 不證明只有一次主要漂移；且零權重的 P1/P2 根本不進入加權預測，不能又說其稀釋 P3。僅搜尋 k=1、2 也不等於無須限定漂移次數。

**修法**：改為「此協定未從第二個非零加權群組獲得增益」，將危機與初始期機制列為可能解釋；偵測器結論限於實際測試的 ADWIN／DDM／PHT、信號與參數。不要由少數未觸發實驗推論傳統偵測器普遍無法處理該問題。
