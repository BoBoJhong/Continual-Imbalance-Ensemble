# 易讀說明、粗體與 XAI 定位

## 使用者要求與實作

- 結果分數：Baseline 在同一分類器版本內比較 Old／New／Retrain；採樣明細在同版同策略內比四採樣；年度表在同年度比八方法；FS 每欄在九個特徵條件中比較。顯示四位小數相同者並列。粗體是閱讀提示，不表示統計顯著，也沒有回選 Test 最佳設定。
- 超參數：固定 Old 1999–2011／Hybrid 情境展示六組已保存的驗證選定值。TabICL 缺同欄位不補造；不同情境的選參可能不同。早期 XGBoost 學習率 0.3 與目前候選集合的版本差異已在正文交代。
- 文字：第三、四章補上合併四年結果、以公司重抽樣、隨機種子標準差及 Holm 校正的直接說明。數學定義、原分數、差值及 165 項檢定保留。
- XAI：區分解釋模型與選取特徵，將本研究 LightGBM 樹模型貢獻值排序定位為 XAI 導向 FS 代表方式；未宣稱最新、未新增方法，亦未把十種子入選次數當作正式排名檢定。
