# 國立中央大學資訊管理學系碩士論文 LaTeX（2026 自製更新版）

**非中央大學官方認證模板。** 以使用者提供的 2013 年歷史範例及中央大學目前公開之 114 學年度格式條例、114.09.25 撰寫體例參考整理，適用一般中文碩士論文的起稿與排版。封面及格式最後請與當年度資管系／教務處／圖書館確認。

## 開始使用（Overleaf）
1. 在 https://www.overleaf.com/ 登入，點 `New Project` → `Upload Project`，上傳整份 ZIP。
2. 左上角 `Settings` → `Compiler` 選 **XeLaTeX**；`Main document` 選 **main.tex**。
3. 開啟 `config.tex`，填入正式題目、姓名、指導教授、**離校年月**；設定是否著作彙編。
4. 於 `chapters/` 撰寫各章；於 `frontmatter/` 編輯中英文摘要、誌謝、符號說明。
5. Zotero / Better BibTeX 可將所有引用匯出至 `references.bib`。本模板使用 **biblatex + Biber**，請保留編譯器 XeLaTeX。
6. `forms/` 放入實際正式表單的 PDF，遵循資料夾內的檔名與順序。**缺少正式表單時仍能編譯，但不能當成可提交的定稿。**
7. 點 `Recompile`，首次建立引用／目錄時需要多次編譯，Overleaf 通常會自動處理。

## 與 2013 年版相比的主要更新
- 改成易維護、不同檔案分章的 UTF-8 專案；移除舊模板對「標楷體」、過時 `xunicode`、debug showframe 及其他非必要套件之硬相依。
- 中文字型優先採用 Overleaf / TeX Live 常見的 `Noto Serif CJK TC`，編譯器預設 XeLaTeX。
- 使用 `geometry` 設定 A4，上下 2.5cm、左 3cm、右 2cm，頁碼置中離底端約 1.5cm。
- 1.5 倍行距，章名置中，中文章次與 1-1、1-1-1 節次；圖／表／公式不因新章重置。
- 加入內頁書名頁、正式文件自動匯入位置，以及新制論文裝訂次序。
- 中英文摘要至符號說明用小寫羅馬數字；正文至附錄用阿拉伯數字。
- 使用 Zotero 可用的 BibLaTeX + Biber 數字引用格式及基本範例。
- 移除舊例大量非論文性質的 PDF、演講稿、測試檔。舊 `.cls` 的原作者資訊仍保留於 `legacy_reference/` 供核對。

### 注意事項
- 中文／英文摘要 **均須提供**，正式撰寫約 300–500 字／words，示例段落不符合字數要求。
- 裝訂順序依 114.09.25 參考體例：封面、書名頁、授權書、適用時延後公開申請書、推薦書、著作彙編資料（若適用）、口試審定書、中英文摘要、誌謝、目錄、圖目錄、表目錄、符號說明、正文、參考文獻、附錄、封底。
- 碩士論文紙本封面應為**暗紅色**，列印紙張 A4；真正的封底與書脊屬於裝訂設計，模板不會用彩色底取代封面紙。
- 依系上公告，7／8 月畢業離校者，封面年月請填當年 6 月；題目應與學位考試文件完全一致。
- 系所／實驗室若有指定格式、引用樣式，**優先依其規範**；本模板的數字引用依官方參考體例示範，但 BibLaTeX 通用樣式未必完整符合文獻條目所有中文標點規定。
- `forms/*.pdf` 不應上傳任何含未經授權個資的文件到公開 GitHub 專案；Overleaf 專案也要妥善設定權限。
- 如果要採**著作彙編**形式，還有各篇共同作者貢獻聲明、綜合論述等特別要求，本模板提供插入入口但不自動產生簽署文件。

## 本機測試
安裝 TeX Live、XeLaTeX、Biber 後，在根目錄執行 `latexmk -xelatex -interaction=nonstopmode -halt-on-error main.tex`。

## 預覽說明
預覽 PDF 僅用於確認排版。正式封面姓名、英文摘要、研究數據、口試簽署頁及引用資料請逐一更新與核對。
